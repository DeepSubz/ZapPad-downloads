# ZapPad for Mac

Currently offered to US customers only. Requires Apple Silicon (M1+) and macOS 27+.

[Download and product information](https://evolute-llc.com/zappad/) · [User manual](https://evolute-llc.com/zappad/help/) · [Privacy](https://evolute-llc.com/privacy-policy/) · [Terms](https://evolute-llc.com/terms/)

Use the latest production DMG for a normal installation. The ZIP is the signed Sparkle update package. The application and DMG are Developer ID signed, notarized and stapled. The automatic 14-day app trial needs no email or card and does not start billing.

Annual license: $29.99 USD paid once for a year of updates. Monthly: $2.99 USD/month, $35.88 over twelve paid months. Cancel Monthly anytime; future charges stop with no balance owed. Before twelve confirmed paid months, access ends with the paid month. Covered-build fallback and revocation follow the linked license terms. Up to three activated Macs.

`appcast.xml` is the production update feed. Explicit QA prereleases and `qa/` feeds remain separate and must not be used as customer releases. Public release files and feeds only; application source is private.
